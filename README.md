# 🦷 Dental AI Chatbot – Demo

An AI-powered dental clinic assistant that helps patients **book appointments** and handles **dental emergencies** through a simple chat interface.

Built with **FastAPI** + **OpenAI API** + vanilla HTML/JS frontend.

---

## 🚀 Feature

- 💬 Conversational chatbot for appointment booking
- 🚨 Emergency detection (bleeding, severe pain) with instant alert
- 📋 Step-by-step booking flow (Name → Phone → Date → Time)
- ✅ Phone number validation (10-digit)
- 😊 Greeting & identity handling ("who are you", "hi", etc.)
- 🔁 Session reset after each booking

---

## 🛠️ Tech Stack

| Layer     | Technology          |
|-----------|---------------------|
| Backend   | FastAPI (Python)    |
| AI/LLM    | OpenAI API          |
| Frontend  | HTML + JS (Static)  |
